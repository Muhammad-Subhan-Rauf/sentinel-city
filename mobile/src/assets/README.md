# Mobile assets

This folder needs four PNGs for Expo to bundle correctly:

- `icon.png` — 1024x1024 app icon
- `splash.png` — 1284x2778 splash screen
- `adaptive-icon.png` — 1024x1024 Android adaptive icon foreground
- `favicon.png` — 48x48 web favicon

Drop your own brand assets here, or run `npx expo install --check` once dependencies are installed and Expo will offer to generate placeholder assets. Until then, the dev build will surface a warning but still run.
